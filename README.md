## Setup

```powershell
py -3.11 -m venv .venv                  # or reuse the existing .venv
.venv\Scripts\python -m pip install -r requirements.lock.txt
Copy-Item .env.example .env             # P1 reads GEMINI_API_KEY, P2 reads GEMINI_API_KEY_P2 (never committed)
```

**Number policy.** Every reported number is tagged:
- **[MEASURED]**: from our own runs and logs;
- **[PROJECTED]**: public prices × stated assumptions;
- **[ESTIMATE]**: planning only.

Every API call is cached and replayable. Hard spend caps apply (P1 $1.5 + P2 $3.5 = $5), and billing is never enabled by the code.
